# Стенд «Каминский» — превью

Квиз «А что для вас роскошь?» для стенда делового центра «Каминский», собранный в один HTML-файл.

- `index.html` — сравнение двух палитр: светлая (новое ТЗ) и бордовая;
- `stand.html` — сам стенд: `?theme=light` или `?theme=dark`, для горизонтальной панели `&rotate=90`.

Сайт собирается из исходного проекта командой `npm run build:pages` и не правится вручную.
